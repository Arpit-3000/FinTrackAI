# 💰 FinTrack AI

A modern cross-platform Personal Finance Tracker built using **React Native (Expo)** and **Node.js**. The application helps users efficiently manage their income, expenses, budgets, and financial insights through an intuitive mobile interface.

## ✨ Features

- Secure Authentication
- Dashboard with Financial Overview
- Income & Expense Management
- Category-wise Transactions
- Budget Planning
- Analytics & Charts
- Profile Management
- Responsive FinTech UI
- Persistent Login
- REST API Integration

## 🛠️ Tech Stack

### Mobile
- React Native
- Expo
- TypeScript
- React Navigation
- React Hook Form
- Zustand
- AsyncStorage

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- REST APIs
